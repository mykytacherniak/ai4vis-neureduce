Introduction

For this assignment, our task was to use an AI agent while completing one of our course assignments and to reflect on the experience. Overall, using AI changed the nature of the work more than we expected. It did not simply speed up what we would have done anyway; it shifted where our time and effort went, from producing the solution to making sense of it.

Efficiency and ease of completion

The most obvious effect of using AI was how much easier and faster the process became. The agent needed only a single prompt, and formulating that prompt was not difficult as long as we knew our model, our data and our research objectives. In fact, simply entering the task description together with the main attributes of the model and the data was enough to produce a nearly complete solution. What would normally have taken many hours of writing, debugging and testing was reduced to a few minutes of preparation and waiting. The resulting code ran correctly and delivered the expected output, so in terms of time and efficiency the benefit was clear.

From writing code to understanding it

At the same time, the generated solution was quite overwhelming to understand. The code worked, but it was not immediately clear what each part did, why particular choices had been made, or how the steps fit together. As a result, the time we saved on writing was largely shifted towards reading and interpreting. Instead of building the solution step by step, and understanding it naturally along the way, we were presented with a finished product that we had to work through backwards. This is a fundamentally different way of learning: the challenge is no longer how to write the code, but how to fully comprehend code that someone (or something) else has written.

The temptation to skip understanding

Because the code worked perfectly, we felt a real temptation to neglect understanding it in full. This was not due to a lack of interest; we were genuinely curious about how the solution worked. Rather, it came from the circumstances we were in. We are working on many assignments at the same time, and the grading focuses on whether the task is completed, not on whether we understand the code behind it. When a working solution is already in hand and time is limited, it is easy to accept it and move on to the next deadline. In this sense, AI makes it possible to meet the formal requirements of an assignment without necessarily meeting its learning goals.

Conclusion

Our main takeaway is that AI makes completing the task easy, but understanding the result still requires time and deliberate effort. Given more time, a full understanding of the generated code would be entirely feasible, and the AI itself could even help with this by explaining its own output. The real limitation is therefore not the tool but how we choose to use it under time pressure, and how assignments are assessed.
